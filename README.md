# Simon Says Game

A fun and interactive Simon Says Game built using HTML, CSS, and JavaScript. 
This memory-based game challenges players to remember and repeat an increasingly complex sequence of colors and sounds.

# Features
Interactive gameplay with color animations.
Random sequence generation.
Increasing difficulty levels.
Score and level tracking.
Responsive and user-friendly interface.
Game over and restart functionality.

# Technologies Used
HTML5 – Structure of the game.
CSS3 – Styling, animations, and responsive design.
JavaScript – Game logic and interactivity.

# How It Works
The game highlights a random color sequence.
The player must repeat the same sequence by clicking the buttons.
Each correct round adds a new color to the sequence.
The game continues until the player makes a wrong move.

# Purpose
This project was created to practice:
JavaScript event handling.
DOM manipulation.
Arrays and sequence logic.
Game development fundamentals.
Responsive UI design.
